# Controlled-access input directory

Place local analysis inputs here only when running the project. Everything else in this directory is ignored by Git.

Expected filenames:

- `Scharfelab-NBS1474samples-250207.xlsx`
- `1000G_378.5.Q`
- `1000G_378.fam`
- `sample_pure.txt`
- `all_phase3.psam`
